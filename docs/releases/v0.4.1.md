## Upgrading from v0.4.0

Run `qgate update`, then bump the pinned version and rewrite the agent skill:

```sh
qgate update                      # installs v0.4.1 over the running binary
$EDITOR qgate.toml                # qgate_version = "0.4.1"
qgate install                     # writes the skill for v0.4.1
git add qgate.toml .claude/skills/qgate .agents/skills/qgate
git commit -m "Upgrade qgate to v0.4.1"
```

Coming from v0.3.0 or earlier, follow the v0.4.0 notes first: delete any
`[approvals]` section and run `install.sh` once, since `qgate update` is new in
v0.4.0. Code is measured the same way, so baselines don't need to be recreated.
